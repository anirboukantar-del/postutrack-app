# PostuTrack

PostuTrack is a desktop application designed to organize, track, and optimize internship or job applications. More than just a dashboard, it integrates artificial intelligence to dynamically tailor a master resume and cover letter for each new job posting.

Available in French and English.

Contains code generated by artificial intelligence with systematic human verification.

## Key Features

*   **Interactive Dashboard:** Overview of statistics (Total applications, Interviews, Offers received).
*   **Application Management:** Precise tracking of sent applications with status management (Applied, In Progress, Interview, Offer, Rejected), contract types, and links to job postings.
*   **AI Resume & Letter Tailor:** Custom generation of resumes (RenderCV compatible) and cover letters by analyzing the job description. Supports multiple AI models.
*   **Centralized Profile:** Automatic form filling via master resume import (PDF/TXT) and secure API key management.
*   **Local Backup:** Data remains private thanks to `localStorage`. A JSON import/export system makes it easy to backup and restore information.

## Installation

### Option 1: Direct Download (Recommended)

If you just want to use the application without setting up a development environment, you can download the final executable:

1.  Go to the [Releases page](https://github.com/anirboukantar-del/postutrack-app/releases).
2.  Download the latest installer file (e.g., `.exe` or `.msi`).
3.  Double-click the downloaded file and follow the standard installation instructions.

### Option 2: Build from Source (For Developers)

**Prerequisites**
*   [Node.js](https://nodejs.org/) (and npm)
*   The [Rust and Tauri prerequisites](https://tauri.app/v1/guides/getting-started/prerequisites) installed on your machine.

**Quick Start**

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/anirboukantar-del/postutrack-app.git](https://github.com/anirboukantar-del/postutrack-app.git)
    cd postutrack-app
    ```

2.  **Install dependencies:**
    ```bash
    npm install
    ```

3.  **Run the application in development mode:**
    ```bash
    npx tauri dev
    ```

4.  **Build the final application:**
    ```bash
    npx tauri build
    ```
